# SeaPoint MVP

부산 항구·해안의 해양 쓰레기 축적 가능성을 100m × 100m 격자 히트맵으로 보여주는 모바일 웹 앱 프로토타입입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 지도를 정상적으로 불러오려면 인터넷 연결이 필요합니다.

## 현재 분석 방식

`app.js`의 `calculateAccumulationScore`가 아래 지표를 0~100으로 정규화해 합산합니다.

| 지표 | 가중치 |
| --- | ---: |
| 저유속 지속도 | 25% |
| 흐름 체류 특성 | 20% |
| 항구 폐쇄도 | 20% |
| 항구 안쪽 풍향 | 15% |
| 파고 안정도 | 10% |
| 하천·선박 등 유입원 | 10% |

현재 화면의 관측값은 시연용입니다. 실서비스에서는 서버가 KHOA 조류·조석 API, 기상청/해양기상 풍향·풍속·파고 데이터, OpenStreetMap 구조 데이터를 3~6시간마다 수집한 뒤 각 100m 격자의 `factors`를 생성하면 됩니다. 이후 실제 청소량·제보 데이터를 학습 데이터로 저장해 가중치 보정 또는 ML 모델로 고도화할 수 있습니다.
